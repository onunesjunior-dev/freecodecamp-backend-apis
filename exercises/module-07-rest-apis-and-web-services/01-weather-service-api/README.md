# Weather Service API

Oficina do Módulo 7 (API REST e Serviços Web) — 20/20 passos. API Express com
arquivos estáticos (`express.static`), `res.sendFile`, parâmetros de rota
(`req.params`), manipulador encadeado (`app.route().get().post()`) e roteador modular
em `weather.js` que consome um proxy meteorológico externo com `fetch`.
