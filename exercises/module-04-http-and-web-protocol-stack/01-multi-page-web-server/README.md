# Multi-Page Web Server

Oficina do Módulo 4 (HTTP e o Modelo de Padrões Web) — 60/60 passos. Servidor HTTP
nativo em Node.js (ESM, sem Express) que serve uma aplicação cliente de múltiplas
páginas com `http.createServer`, roteamento estático via `path.join`, mapeamento de
MIME types por extensão e fallback 404 para rotas inexistentes.
